# Research scope

The strongest supported statement is that recomputing a predicate from retained
values does not by itself establish that those values came from the declared
execution. The controlled correspondence records show that plan and native-byte
checks reject contradictions that predicate replay alone accepts. The request-
history control shows that explicit return-value dependencies can omit an
intermediate request that changes a stateful recovery result even when the paired
artifacts are byte-identical.

The project does not claim that every earlier request is causally necessary,
that complete prefixes are universally minimal, that evidence projection is a
compression method, or that compatibility with another framework establishes
framework superiority. External LLVM and SandMark records remain retained
native evidence unless their complete acquisition entry points are rerun with
the required external inputs.

## Repository boundary

This repository contains the executable research implementation, tests, study
receivers, acquisition drivers, and compact validation fixtures. Manuscript
sources and publication-layout figure tooling are intentionally distributed
separately so that a code checkout does not contain redundant publication
assets or internal editorial history.
